# Telvi
Telvi is a collaborative virtual study-room platform built for learning together online. It combines realtime chat, user profiles, room-based communities, shared YouTube sessions, file and voice-note sharing, Pomodoro study tools, task management, and a multiplayer whiteboard with live cursors
